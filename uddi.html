🔍 Servicio: Consulta de Estudiantes por ID

Proveedor: Integrante 1 (Backend)

Descripción: Servicio web SOAP que permite consultar información académica de estudiantes utilizando su identificador único (ID).

📄 WSDL (Web Services Description Language)

Archivo de descripción del servicio para que los clientes puedan consumirlo:

🔗 Ver WSDL del Servicio

URL del WSDL: http://localhost/Taller_WEB_SERVICES/servidor.php?wsdl

🌐 Endpoint del Servicio

http://localhost/Taller_WEB_SERVICES/servidor.php

Usa esta URL en tu cliente SOAP para consumir el servicio.

📌 Método Disponible

MétodoParámetro (entrada)Tipo de retornoDescripción
obtenerEstudiantePorId id (string o int) Estructura Estudiante Devuelve los datos completos del estudiante si existe

💻 Ejemplo de consumo (cliente)

Para el Integrante 2 - Código para cliente.php:

<?php
$options = array(
    'uri' => 'http://localhost/Taller_WEB_SERVICES/',
    'location' => 'http://localhost/Taller_WEB_SERVICES/servidor.php'
);
$client = new SoapClient(null, $options);
$resultado = $client->__soapCall('obtenerEstudiantePorId', array('1'));
print_r($resultado);
?>
